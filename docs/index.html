AdFree — Usage Guide

A small macOS app that opens YouTube and Twitch with ad blocking built in, and nothing else. Part of Artifact 2.

What it is

AdFree is a native macOS window around a web view (the same engine Safari uses). You browse the real YouTube and Twitch, signed in as yourself, but the app strips ad data from YouTube's player, filters ad segments out of Twitch's video playlist, and blocks known ad hosts. Because it only opens sites on an allowed list, stray links can't take you anywhere else.

Requires macOS 14 or newer and Xcode (for building). A short demo video is on the Artifact 2 page.

Install and run

git clone https://github.com/Eagle-Scout/TCSS-490-Black-2.git
cd TCSS-490-Black-2/AdFree
./build.sh run

build.sh compiles the app, assembles build/AdFree.app, signs it with the App Sandbox turned on, and opens it. The app has its own shield-and-play icon. Drag AdFree.app into Applications if you want to keep it. Run ./build.sh again after pulling changes.

First launch: because the app is sandboxed, it keeps its own cookies. Sign in to Google once inside AdFree to get your history and subscriptions. After that, you stay signed in.

If a site can't load (it doesn't exist, you're offline, it times out, or it has a certificate problem) or comes back with an error page like 404, a yellow notice at the top says why. A home-page card that fails sends you back to the home page, so a mistyped site never looks like a redirect.

Allowed sites and the home page

The home page is your allowed list: every allowed site has a card, and a site only leaves the home page by being removed from the allowed list. (youtu.be is a short-link alias of YouTube, so it has no card.) Open Settings → Allowed sites. YouTube, Twitch and their subdomains are allowed by default, and youtube.com can't be removed because blocked links are sent there. Any link outside the list is cancelled, a yellow notice appears, and you land on YouTube.

To add a site, type its address (for example kick.com) and press Add…. You'll be asked to confirm, because anything on an allowed site, including scams or fake sign-in pages, can load inside AdFree. Only add sites you trust. Google's sign-in pages are allowed automatically, but Google search is not.

When an ad gets through

YouTube and Twitch change their code often, so blocking breaks now and then. Press Ads showing? and work down the list:

  1. Reload the page. Fixes most one-off misses.
  2. Reload blocking files. Re-reads the rules and scripts and reloads the page.
  3. Clear the cache. Removes cached pages and scripts. You stay signed in.
  4. Run a diagnosis and copy the report. It shows what the app sees on the current page. Paste it to whoever is fixing the scripts (for example, to Claude with "ads are getting through on YouTube, please update the scripts").
  5. Edit the scripts in Settings (next section).

If a page won't load at all, go to Settings → Blocking and switch the layers off one at a time (network rules, YouTube script, Twitch script). The one that makes the page work is the one that's broken.

Editing the scripts and rules

Settings → Scripts & rules has an editor for the three files that do the blocking:

FileWhat it controls
ContentRules.jsonHosts and URL patterns that are blocked, plus page elements that are hidden. Apple's content blocker format.
youtube-adblock.jsStrips ad data from YouTube's player responses; skips or hides any ad that still shows.
twitch-adblock.jsRemoves ad segments from Twitch's playlist; if the whole playlist is ads, swaps in the same stream requested as another player type; mutes any ad that still plays.

Pick a file, edit it, and press Save and apply (⌘S). The app checks the syntax first, so a typo can't break blocking, then reloads the page. Show in Finder opens the folder holding your saved copies. Revert to built-in deletes your copy.

A saved copy replaces the built-in file. If the app is later updated with a fixed script, your copy keeps shadowing it until you revert. The editor labels files "Custom copy in use" so you can tell.

To change what ships with the app, edit the files in AdFree/Resources/ in the repo and run ./build.sh. To redraw the icon, run AdFree/tools/make-icon.sh. To regenerate the demo video shown on the Artifact 2 page, run swift AdFree/tools/make-demo.swift docs/media/adfree-demo.mp4 from the repo root.

For a headless check that Twitch still plays, run ADFREE_SELFTEST=1 build/AdFree.app/Contents/MacOS/AdFree. It opens a live channel, samples the video twice and prints whether playback is advancing. Set ADFREE_LAYERS=rules,youtube,twitch (any subset) to test with layers off. In Safari, Develop → this Mac → AdFree opens the Web Inspector for the app.

Security notes

  • Sandboxed: the app can only touch its own container and the network, so a bug in it can't read your documents.
  • Limited navigation: only allowed sites open, and there is no address bar.
  • Not included: Safari's phishing warnings and passkey integration. The app is ad-hoc signed, not notarized.
  • Custom scripts: a saved copy runs inside your signed-in YouTube session. Only save code you understand. Revert to built-in if in doubt.

Limits

  • This is a cat-and-mouse game. YouTube and Twitch change their code, so scripts will need updates.
  • Twitch ads are spliced into the video stream, so a brief stall or lower-quality moment at an ad break is possible. The backup-stream swap is best effort.
  • Blocking ads goes against both services' terms of service. This is a personal and educational project. YouTube Premium and Twitch Turbo are the supported way to remove ads.
